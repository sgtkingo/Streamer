Uživatel by měl být při prvním otevření appky vyzván k tomu, zda si chce založit účet a nastavit své preference a také most i API stream serveru. 

Uživatel může pro přihlášení použít účet Google, Apple ID či okální heslo/jméno. 

Uživatel bude muset nastavit most k stream API službě - například Webshare přihlašovací údaje.

Uživatel si může volitelně nastavit preference, tím pomůže aplikaci nabízet relevantní obsah. I pokud je nenastaví, aplikace si bude inteligetně stavět profil uživatele dle jeho historie sledování.

Všechny uživatelské informace musí být šifrovány, a uživatel o tom musí být decentně informován ať ví že jeho data jsu v bezpečí.
